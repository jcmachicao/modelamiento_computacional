# Modelamiento Computacional

A vewces se dice muy ligeramente que "los algoritmos no piensan", y esto si bien la afirmación correcta sería que los algoritmos computacionales no piensan como lo hacen los seres humanos, podría llevar a la idea de que es imposible asignarle funciones cognitivas a los algoritmos computacionales, algo que es falso. Sí es posible transferir algunas funciones cognitivas a algoritmos.

En este repositorio se comparte algunos experimentos en los cuales se logra hacer que algunos algoritmos "piensen" computacionalmente.
